# AstrBot 内存守护
为 AstrBot 提供定时与内存压力触发的进程内存回收，适用于 Windows、Linux、macOS。插件运行期间无需管理员或 root 权限。

在 AstrBot 插件管理中输入本仓库地址安装。默认每 30 秒检查，系统内存使用超过 60% 时尝试回收，两次至少间隔 5 分钟。即使内存未达阈值，也每 15 分钟回收一次。

回收内容为 AstrBot 进程中已无引用的 Python 对象。在支持 glibc 的 Linux 上，额外通过 malloc_trim 将已释放的堆页返还系统。Windows 与 macOS 使用 Python 垃圾回收和各自的正常内存分配器。仍在使用的模型、记忆、消息和数据库由应用继续管理。

效果取决于当时可释放的对象。记录真实 RSS 前后差值，不保证固定释放比例。插件不执行系统级 drop_caches，不清理磁盘文件，不终止其他进程，不调用模型，不注册聊天或工具钩子。系统整体内存不足仍需检查实际占用进程。

配置可在插件设置页修改。status.json 位于插件自己的数据目录，保存最近检查和回收结果，固定覆盖一个不超过 16 KiB 的文件。卸载或重载会等待当前回收结束，再停止定时任务。

## 本地测试
安装 requirements.txt 后运行 python -m unittest -v test_guard.py。
公开源码与合成测试均不包含服务器配置、聊天、账号或凭据。
